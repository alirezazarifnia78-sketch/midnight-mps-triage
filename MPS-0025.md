# Triage: MPS-0025, Source-of-funds evidence for incoming shielded assets

**Source:** [mps-0025-shielded-source-of-funds.md](https://github.com/midnightntwrk/midnight-improvement-proposals/blob/main/mps/mps-0025-shielded-source-of-funds.md)
**Category:** Core · **Status:** Proposed · **Created:** 2 Jun 2026 · **Parent:** MPS-0006

## Summary

A regulated custodian can see that a shielded asset has **arrived**, but not **who sent it or how it was routed**. Without that, it can't run the AML, sanctions and travel-rule checks it needs before crediting, redeeming or passing the asset on. The MPS separates three steps: receipt, attribution and acceptance. Shielded transfers today give receipt but not attribution.

## 1. Complete?

Mostly. The abstract, problem, use cases, goals and open questions are all solid. Two gaps:

- The trigger for **when** evidence is required is never defined.
- Expected outcomes are qualitative, with no way to tell when the problem is solved.

## 2. Clear?

Yes. The receipt / attribution / acceptance split is the clearest part of the document, and the five use cases (credit, institution-to-institution, quarantine, audit, redemption) are concrete.

## 3. Duplicates and overlaps

It's part of the **custody cluster**: MPS-0006, 0016, 0018, 0024 and 0035, with MIP-0012 and MIP-0017. The parent link to MPS-0006 is declared. The boundaries with MPS-0024 (custodian-safe shielded spends) and MPS-0035 (shielded spend key exposure) should be stated explicitly.

**Gate:** compliance and privacy review needed. Any evidence mechanism changes what is disclosed, and to whom.

## 5. Recommendation

**Move forward after small fixes.** This is a real blocker for regulated institutions. From fintech KYB/AML work, source-of-funds evidence is one of the first things a compliance team asks for before accepting money.

## Questions for the authors

1. Which events trigger the requirement for evidence (amount, counterparty type, jurisdiction)?
2. How would we know the problem is solved? What would a custodian be able to do that it can't today?
3. Can you state the boundary with MPS-0024 and MPS-0035 in a sentence each?
4. Could the mechanisms listed in the goals move to a linked draft MIP, so the MPS stays solution-neutral?
